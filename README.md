## 🌟 Created & Architected by Shahzaib Ali

**Brohi Clips Pro** is an open-source, serverless mobile video production studio designed to convert horizontal YouTube and Twitch live streams into high-converting 9:16 vertical Shorts & Reels — right on your Android device.

---

## 🔑 100% BYOK (Bring Your Own Key)

To protect developer and user privacy:
- The app uses **zero hardcoded developer API keys**.
- Every user simply enters their own free Google Gemini API key inside the app Settings.
- Get a free key in 30 seconds at [Google AI Studio (aistudio.google.com)](https://aistudio.google.com/app/apikey).
- Keys are stored strictly on your local device.

---

## ✨ Features

- 🧊 **3D Imperial Gold Subtitles**: High-impact word-by-word bouncing captions with 3D isometric bevel drop shadows.
- 🤖 **3D AI Talking Avatar**: Interactive WebGL robot host hook.
- 📡 **Live Stream Scanning**: Sniffs streams via `yt-dlp` without downloading huge video files.
- ⚡ **Local Hardware Encoding**: Uses `h264_mediacodec` and FFmpeg for high-speed local rendering.
- 👑 **Dedicated Creator Screen**: Built-in developer profile honoring **Shahzaib Ali**.

## 🛠️ Tech Stack

- **Android Host**: Java / AppCompat, WebKit
- **3D Graphics**: Three.js WebGL
- **Video Engine**: FFmpeg (`libass`, `h264_mediacodec`), `youtubedl-android` (Python 3.12)
- **AI Brain**: Google Gemini 2.0 / 2.5 Flash API (BYOK)
- **CI/CD**: GitHub Actions Automated Cloud Builds
